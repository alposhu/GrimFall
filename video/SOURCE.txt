Video
=====

intro.mp4   the opening cinematic
menu.mp4    the title screen's moving backdrop

Both are built by scripts in tools/assets/ from masters in art-source/, which
are NOT in this repository — see .gitignore. Only the encoded derivatives ship.

THE OPENING CINEMATIC
  Supplied by the project owner. Built by tools/assets/build-intro.py, which
  re-encodes at CRF 26, moves the index to the front for streaming, and mixes
  audio/boss-sovereign-intro.mp3 under the film's own soundtrack.

THE TITLE BACKDROP
  A looping pixel-art scene: a knight resting by a campfire under a night sky.
  Supplied by the project owner as `mainmenu.webm`. Built by
  tools/assets/build-menu-video.py, which halves it to 720p, strips the audio
  track and re-encodes to H.264.

  ---> ACTION NEEDED BEFORE RELEASE <---
  The file arrived with no licence, no readme and no author credit, so unlike
  the art and audio in this project its terms are NOT established. Find where
  it came from and confirm what it permits. If it needs attribution, add it to
  the in-game credits; if it is not licensed for use in a released game, the
  backdrop has to come out.

  Nothing depends on it. `src/ui/ui.js` loads it on demand and fails quietly:
  a missing file, an unsupported codec or a refused autoplay each leave the
  title screen on its plain background, which is what it looked like before
  there was a film at all. Deleting video/menu.mp4 is a complete removal.

  This note exists so that this one does not quietly become the exception —
  see audio/SOURCE.txt, fonts/SOURCE.txt, img/SOURCE.txt, img/ui/SOURCE.txt
  and img/rtp/SOURCE.txt, all of which record their terms.
