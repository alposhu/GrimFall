The Grimfall wordmark
=====================

logo.png, logo-small.png, icon-192.png, icon-512.png and the two images in
.github/ are all generated by `tools/assets/build-logo.py`. None of them is
hand-drawn, and none should be edited by hand - re-run the script instead.

THE FACE
  "{PixelFlag}" by NAL, built with FontStruct.
  http://fontstruct.com/fontstructions/show/578475
  Licensed CC BY 3.0 - http://creativecommons.org/licenses/by/3.0/

  Its characteristic is a rule running above and below the word, so the type
  arrives already looking like a banner. That is the whole logo: there is no
  drawn mark, no glow and no bevel.

  The .ttf is NOT shipped with the game. Only its rendered output is, so the
  font never has to be redistributed - which also means its archive's condition
  that redistribution include every file from the archive never arises. NAL is
  credited in-game and in README.md regardless.

HOW IT IS DRAWN
  The face is rendered at 16px, the size its author specifies for pixel use,
  and upscaled by a whole number with nearest-neighbour. Asking the rasteriser
  for 96px directly gives soft, unevenly hinted stems, which is the one thing a
  pixel logo cannot have. The one-pixel ink outline is a dilation of the glyph
  mask at SOURCE scale, so it stays exactly one pixel after upscaling.

  The app icon sets GRIM over FALL, because a word this wide cannot be a square
  icon, inside a plain double rule - the interface's own filigree is one pixel
  wide at 192px and reads as noise.

  To rebuild, point the script at the .ttf:

    GRIMFALL_LOGO_FONT=/path/to/{PixelFlag}.ttf python tools/assets/build-logo.py
