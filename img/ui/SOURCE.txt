Interface art
=============

Everything here is cut by `tools/assets/build-ui-art.py` from three free packs.
Only the pieces the interface actually uses are copied, and nothing is tinted.

EXPORTED AT 3x
  The frames, buttons and slots are exported pre-scaled with nearest-neighbour.
  The RPG kit is DRAWN small and MEANT to be shown big - its wood frame is four
  pixels and its buttons twelve tall - so at 1:1 in a browser the frame is a
  hairline and the whole interface reads as a thin cartoon outline. Scaling is
  done here rather than left to CSS because `border-image` does not reliably
  honour `image-rendering: pixelated` when it scales slices, and a smoothed
  nine-slice has half-pixel edges, which is the one thing this interface exists
  to avoid.

PANELS, BUTTONS, HEADERS, SLOTS
  "Free Basic Pixel Art UI for RPG" by CraftPix
  https://craftpix.net/freebies/free-basic-pixel-art-ui-for-rpg/
  Licence: https://craftpix.net/file-licenses/

  Free for personal and commercial projects, modification allowed, NO
  attribution required - it is credited in-game and in README.md anyway, which
  is how this project treats every asset whose author asked for nothing. The
  source files may not be resold or redistributed as art, and may not be used
  to train generative A.I. Neither happens here: only cut, scaled derivatives
  ship, inside a game.

  It was chosen over the other packs because it is a COMPLETE kit rather than a
  set of frames. The panel, its green title bar, the close button, the buttons,
  the checkboxes, the dropdown and the slot squares are all drawn by the same
  hand, and an interface assembled from four packs never quite looks like one
  thing. It also reads better: near-black on parchment is the contrast every
  guide on game interfaces asks for, and it survives a phone in daylight in a
  way the previous pale-on-dark-violet theme did not.

  Cut from `Settings.png`, measured off the source rather than eyeballed:
    x 7..10    wood border, 4px        y 0..13    the green header bar
    x 11..100  parchment body          y 14..148  the body, wood-framed
    x 101..104 wood border, 4px
  The header's own X sits at x 92..101, so the header is cut to the LEFT of it
  and the close button is a separate sprite - baking a button into a nine-slice
  would put it in the middle of every wide panel.

THE MARKET'S WARES, AND THE POINTER
  "Complete UI Book Styles Pack" (Travel Book Lite) by Crusenho Agus Hennihuno
  https://crusenho.itch.io - licensed CC BY 4.0
  https://creativecommons.org/licenses/by/4.0/

  Changes made, as CC BY 4.0 requires stating: two slot frames had their
  centres punched out so the fill is a CSS colour, and the two cursors were
  doubled with nearest-neighbour. No recolouring.

  Leather and dark paper against the menus' wood and parchment. The Long Market
  is the one place in this game that is a PLACE rather than an interface, and
  giving its wares a different material says so without a word of explanation.

ICONS
  "Icons Essential" by Crusenho Agus Hennihuno
  https://crusenho.itch.io - licensed CC BY 4.0

  Changes made: thirty-two of the pack's eighty icons were selected and packed
  into one 128x64 atlas, eight to a row. The artwork itself is unmodified.

  THE ORDER IN icons.png IS AN API. css/style.css addresses each glyph by
  background-position, so appending is safe and inserting renumbers everything
  after it. The order is printed by the build script.

A PACK THAT WAS LOOKED AT AND NOT USED
  "Complete UI Essential Pack" (Flat Theme), also Crusenho, also CC BY 4.0.
  Good art, wrong game: cream, sky blue and orange, with no title-bar or slot
  vocabulary. The RPG kit covers the same ground in a register that matches.

IF YOU NEED TO RE-RUN THIS
  The source packs are not in the repository. Download them from the links
  above, unpack them into one folder, and point the build script at it:

    GRIMFALL_UI_PACKS=/path/to/packs python tools/assets/build-ui-art.py
